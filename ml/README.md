# Machine Learning & AI Module

This directory contains research datasets, exploratory data analysis notebooks, training scripts, and serialized models.

## Tech Stack
- **Language:** Python 3.10+
- **Libraries:** pandas, numpy, scikit-learn, joblib, matplotlib, seaborn
- **Notebooks:** Jupyter / VS Code interactive notebooks

## Models & Capabilities
1. **Emergency Priority / Triage Classifier:**
   - Multi-class classification (P1 Critical, P2 Urgent, P3 Moderate, P4 Routine).
   - Trained on vital signs, consciousness levels (AVPU), and trauma features.
2. **Hospital Allocation Utility Scorer:**
   - Multi-criteria decision engine matching patient severity with hospital capacity.
3. **Congestion-Adjusted ETA Predictor:**
   - Real-time adjustment of geometric route travel times based on historical peak traffic windows.
