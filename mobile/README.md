# Mobile Application Module (Android)

This directory contains the cross-platform mobile client built for Android devices using **React Native** and **Expo**.

## Tech Stack
- **Framework:** React Native + Expo
- **Navigation:** React Navigation (Native Stack + Bottom Tabs)
- **Maps:** `react-native-maps` / Leaflet WebView fallback
- **State & HTTP:** Context API + Axios
- **Real-time:** Native WebSocket client

## Implementation Roadmap
- Scheduled for initialization and development in **Milestone 3**.
- Focused on handheld workflows:
  1. Instant Geolocation SOS for Patients/Bystanders.
  2. Turn-by-turn Driver navigation & status toggles.
